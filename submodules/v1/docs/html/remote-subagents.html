Remote Subagents

Open omp. Spawn a subagent. It runs elsewhere — another process, a container, a server — and it feels native: widget, steering, reattach after restart.

Companion docs: design doc · omp/pi core · herdr teardown · hub teardown · repo teardown · protocols survey · headless omp

The one-paragraph answer

The agents repo already contains ~70% of the “agent server”: a stateful gateway (owner-scoped task store, SSE streaming with replay, cancel/ack/list, reaper) and a pi extension that speaks HTTP to it. Missing: a workload-launcher seam (local process / docker / remote runner instead of only k8s pods), a durable store + re-adoption (survive gateway restarts), a streaming worker contract (omp RPC over stdio — steering, tool events, reattach), and an omp extension with widget + commands so remote agents feel native. No new protocol in v1: keep HTTP+SSE, borrow A2A semantics, wrap any CLI behind a driver. ADK is out; ACP waits for its HTTP transport; MCP stays a facade.

One model, four surfaces

The herdr lesson: a “surface” is six operations (create / run / read / inspect / sendKeys / close). Everything else — drivers, completion sidecars, session seeding, lifecycle state machine, registry, steering — is surface-agnostic.

Decisions

Worker contract

A worker is a process the supervisor started, speaking omp RPC JSONL on stdio, bound to a session file the supervisor chose.

  1. Supervisor picks the deterministic session path (race-free, herdr pattern) and launches the driver command (env: PI_SUBAGENT_NAME/ID/SESSION, task as first prompt).
  2. Supervisor watches: agent_settled = completion · tool_execution_* → SSE tool frames · message_end deltas → artifacts · process exit · deadline.
  3. Result = last assistant text; persisted in the task row.
  4. Death before completion: task stays running, reattachable — relaunch driver with --resume <sessionFile>. Mid-task pickup, verified.
  5. Any CLI works: RPC drivers (pi, omp) steer; one-shot drivers (claude, codex, opencode, grok, generic) complete via sentinel/sidecar.
